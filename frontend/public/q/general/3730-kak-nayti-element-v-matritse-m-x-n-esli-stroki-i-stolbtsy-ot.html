Как найти элемент в матрице M x N, если строки и столбцы отсортированы по отдельности (Search a 2D Matrix II)?

Тренировать в Telegram-боте →
База вопросов › General › Searching
💡 Краткий ответ для собеседования
Начинаем с правого верхнего угла (row = 0, col = N - 1) или левого нижнего угла. Если matrix[row][col] == target — найдено! Если matrix[row][col] > target — сдвигаемся влево (col--), отбрасывая весь текущий столбец. Если < target — сдвигаемся вниз (row++), отбрасывая текущую строку. Сложность O(M + N) по времени и O(1) по памяти.

Варианты ответа в приложении:

  • A. Начать с правого верхнего угла: двигаться влево (col--) при > target, вниз (row++) при < target за линейное время O(M + N) Правильный
  • B. Бинарный поиск по всем строкам матрицы за время O(M log N)
  • C. Сортировка всей матрицы в одномерный массив за время O(M*N log(M*N))
  • D. Поиск в такой матрице невозможен быстрее квадратичного времени O(M * N)
