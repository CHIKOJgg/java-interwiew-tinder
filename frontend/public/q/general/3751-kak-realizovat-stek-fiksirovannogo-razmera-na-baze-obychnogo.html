Как реализовать Стек фиксированного размера на базе обычного одномерного массива?

Тренировать в Telegram-боте →
База вопросов › General › Stacks
💡 Краткий ответ для собеседования
Массив arr[capacity] и целочисленный указатель top = -1. push(x): если top == capacity - 1 — ошибка Stack Overflow; иначе arr[++top] = x. pop(): если top == -1 — ошибка Stack Underflow; иначе возвращаем arr[top--]. peek(): возвращает arr[top]. Все операции занимают строго детерминированное время O(1) без аллокаций.

Варианты ответа в приложении:

  • A. Массив и индекс top = -1: push увеличивает ++top, pop возвращает arr[top--], проверка границ дает O(1) время без аллокаций Правильный
  • B. Кольцевой буфер с двумя индексами head и tail, перемещающимися по модулю
  • C. Динамический список с вызовом System.arraycopy на каждой операции push
  • D. Стек на массиве не может быть реализован из-за отсутствия указателей в Java
