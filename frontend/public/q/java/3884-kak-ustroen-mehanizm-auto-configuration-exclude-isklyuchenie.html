Как устроен механизм Auto-configuration Exclude (исключение автоконфигураций)?

Тренировать в Telegram-боте →
База вопросов › Java › Spring Boot
💡 Краткий ответ для собеседования
Если автоконфигурация мешает (например, DataSourceAutoConfiguration при запуске без БД), ее можно исключить: 1. Через атрибут аннотации: @SpringBootApplication(exclude = {DataSourceAutoConfiguration.class}). 2. Через свойство application.properties: spring.autoconfigure.exclude=org.springframework.boot.autoconfigure.jdbc.DataSourceAutoConfiguration.

Варианты ответа в приложении:

  • A. Через атрибут exclude в @SpringBootApplication или свойство spring.autoconfigure.exclude в конфигурационном файле Правильный
  • B. Удалением соответствующих .class файлов из JAR-архива с помощью архиватора 7-Zip
  • C. Исключение автоконфигураций запрещено правилами архитектуры Spring Boot
  • D. Через запуск JVM с флагом -Ddisable.autoconfig=true
