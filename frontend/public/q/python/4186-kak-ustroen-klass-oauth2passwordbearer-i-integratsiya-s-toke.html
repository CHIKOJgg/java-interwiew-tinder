Как устроен класс OAuth2PasswordBearer и интеграция с токенами JWT в FastAPI Security?

Тренировать в Telegram-боте →
База вопросов › Python › FastAPI
💡 Краткий ответ для собеседования
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token") объявляет схему безопасности. В Swagger UI появляется кнопка "Authorize", запрашивающая логин и пароль по форме OAuth2 (x-www-form-urlencoded). В эндпоинтах параметр token: str = Depends(oauth2_scheme) автоматически извлекает токен из заголовка Authorization: Bearer <token>, который затем декодируется и валидируется через PyJWT.

Варианты ответа в приложении:

  • A. Интегрирует схему Bearer токенов: добавляет Authorize в Swagger UI и автоматически извлекает токен из заголовка Authorization Правильный
  • B. Генерирует криптографические ключи RSA на сервере базы данных
  • C. Отправляет SMS-код подтверждения на номер телефона пользователя
  • D. Служебный класс для авторизации запросов через учетную запись Google
