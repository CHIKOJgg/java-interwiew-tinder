Почему функция sys.getrefcount(x) всегда возвращает значение минимум на 1 больше, чем реальное число ссылок на x?

💡 Краткий ответ для собеседования
При передаче объекта x в функцию sys.getrefcount(x) сам аргумент функции внутри вызова создает еще одну временную сильную ссылку на объект x в локальном пространстве имен getrefcount. Поэтому возвращаемое число ссылок всегда включает эту временную ссылку (+1).

Варианты ответа в приложении:

  • A. Сама передача объекта x в качестве аргумента в функцию sys.getrefcount(x) создает дополнительную временную ссылку (+1) Правильный
  • B. Интерпретатор резервирует одну ссылку под глобальную переменную builtins
  • C. Функция getrefcount округляет значение до ближайшего четного числа
  • D. Это ошибка в исходном коде функции, оставленная для обратной совместимости
