  • A. Воркер Celery навсегда зависнет на этой задаче, перестав брать другие задания из очереди; для защиты необходимо настраивать soft_time_limit и time_limit Правильный
  • B. Celery автоматически перезапустит сервер Linux через 10 секунд
  • C. Задача будет проигнорирована и удалена брокером
  • D. Python выбросит исключение MemoryError
